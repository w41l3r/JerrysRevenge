# Security Policy

## Reporting a vulnerability in Jerry's Revenge

Please use GitHub's private vulnerability reporting or a private security
advisory for this repository. Include the affected version, impact, reproduction
steps that use only local fixtures, and any suggested mitigation.

Do not include live target credentials, cookies, customer information, or raw
engagement evidence. If sensitive material was exposed accidentally, rotate or
invalidate it before reporting the software issue.

## Scope

This policy covers vulnerabilities in Jerry's Revenge itself. It is not a
channel for reporting vulnerabilities found in third-party Tomcat deployments.
Report those findings through the target owner's authorized disclosure process.

## Supported version

Until tagged releases are published, only the current default branch is
supported. This section will be updated when the project adopts a release
schedule.
